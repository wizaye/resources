# Interview Prep Resources

No-fluff technical notes for placements, interviews, and job switches. Everything stays in plain Markdown so it remains useful on both the website and GitHub.

## Why This Exists

Interview preparation often becomes a pile of disconnected questions and memorized answers. This project keeps concepts, prerequisites, trade-offs, and practical reasoning together so you can recognize the shape of a problem and explain your decisions clearly.

## How to Navigate

- Start with the [DSA roadmap](./ds-algo/roadmap.md) if you are preparing for coding rounds.
- Use [Data Structures & Algorithms](./ds-algo/README.md) to understand patterns and problem-solving strategy.
- Use [Core CS Fundamentals](./core-cs/README.md) for operating systems, networks, databases, and object-oriented design.
- Follow prerequisites in order, then return to individual pages for revision.

These notes are actively maintained. Expect pages to evolve as explanations, examples, and interview guidance improve.
