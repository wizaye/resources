# Version Control Systems

1. Git (most used):
    - Learn what is git here first to understand the basics : [Git for dummies](https://youtu.be/mJ-qvsxPHpY?si=SZL5JEaR9nGnWrcX)
    - Do this crash course (if you have time and are interested , its around an hour or so): [Git Crash Course](https://youtu.be/mAFoROnOfHs?si=UQYJEXnUFlMEVRSQ)
    - You can use this handbook to refer (official docs): [Git](https://git-scm.com/book/en/v2)

2. Mercurial (used on large production codebases) ( learn only if you are targeting cloud and production systems backend engineer roles) :
    - Tutorial : [Mercurial hands on](https://youtu.be/nMwc61IKPgo?si=u23F2i0n7elmF_-i)
    - Handbook : [Mercurial SCM](https://www.mercurial-scm.org/)

3. Choose any code hosting platform and explore
    - Git Hub (most used in orgs)
    - Bitbucket
    - Azure Dev Ops (its a wrapper around github).
    - Git Lab
